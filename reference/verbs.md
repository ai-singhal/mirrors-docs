title: "Service verbs"
---

Every action the product offers is one verb in the registry; the web app calls it over tRPC, the CLI as its dotted words, and the hosted MCP server as a tool named with underscores. Inputs and outputs are the schemas named here, from the contracts package. Verbs marked as spending compute run models or start tasks; long-running ones answer with an id to poll.

Generated by `pnpm docs:generate`; do not edit by hand.
